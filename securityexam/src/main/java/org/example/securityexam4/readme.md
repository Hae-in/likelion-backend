### 목적
- Database에 있는 사용자를 기준으로 Security를 이용해서 인증/인가를 테스트

### 개발 순서
1. 회원가입
   - 엔티티
   - 레파지토리
   - 서비스: 회원가입 메서드, 회원가입 로직
   - 회원가입 폼
   - 컨트롤러: 회원가입 폼, 회원가입
   - dto

2. 로그인
    - 로그인 폼
    - 로그인 DTO: 생성해서 할것인지 파리메터로 직접 받을지 결정
    - 컨트롤러: 로그인 폼 요청, 로그인 요청(시큐리티가 구현)
    - UserDetailsService: 구현체 작성
    - 필요하면 securityConfig
